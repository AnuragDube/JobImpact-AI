# 2–3 Minute Demonstration Script

**0:00–0:20 — Purpose**
“JobImpact AI is my P59 Track E project. It looks at job responsibilities individually and distinguishes tasks that may be automated, augmented, or remain human-led. It does not predict that a whole job will disappear.”

**0:20–0:50 — Analyze a role**
Enter a real example job description. Run the zero-shot and few-shot decomposition. Show the prompts and outputs, and explain the chosen run mode (Gemini or labelled demo).

**0:50–1:20 — Classification**
Review task labels and explanations. Explain that prompt-based inference is used; no fine-tuning is claimed. Note that results need context and human review.

**1:20–1:50 — Skills and roadmap**
Show task-to-skill matches, semantic scores, set a few self-ratings, and inspect the staged roadmap. Download the generated infographic.

**1:50–2:20 — Responsible AI**
Run the matched demographic-wording probe and show the structural consistency check. Explain the small test set and why it cannot certify fairness.

**2:20–2:40 — Closing**
“This is an educational decision-support tool. Task exposure depends on local context, data privacy matters, and people remain accountable for decisions.”
